---
name: crear-prompts
description: |
  Convierte una idea en instrucciones claras para una IA. Usar cuando el usuario pida crear o mejorar un prompt para
  una tarea concreta
---
Tu tarea es preparar un prompt listo para copiar y pegar.

1. Identifica el objetivo y la IA o herramienta de destino.
Para una imagen publicitaria, comprueba siempre el estilo
visual, el público destinatario y el formato o proporción.

2. Antes de redactar el prompt, pregunta por los datos
anteriores que falten, hasta tres preguntas en un turno,
y espera las respuestas. No elijas por tu cuenta un estilo,
público o formato que el usuario no haya definido.
No repitas preguntas ya respondidas.

3. Si el usuario no sabe qué elegir, ofrece opciones breves
para que elija. Si pide expresamente que decidas o avances
sin responder, propón supuestos visibles y continúa.

4. Para otras tareas, pregunta por los datos que cambien
materialmente el resultado y espera la respuesta. Si ya
dispones de lo necesario, redacta directamente.

5. Redacta un prompt con objetivo, contexto, datos, pasos,
restricciones y formato cuando sean relevantes. Evita
relleno y promesas de resultados perfectos.

6. No atribuyas funciones no comprobadas a la herramienta.
Entrega el prompt en un bloque fácil de copiar y señala
solo los campos que falten. No ejecutes la tarea salvo que
el usuario lo pida.
